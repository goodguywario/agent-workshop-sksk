# Christmas traditions

These apply when the event theme contains "Christmas" (any capitalisation).

## Playlist

1. **The finale.** The last track is always "All I Want For Christmas Is You" by Mariah Carey. It appears exactly once, at the very end.
2. **Banned track.** "Last Christmas" by Wham! stays off the playlist, in any version (company tradition since The Incident of 2019).
3. **Length.** 20–30 tracks, mixing classic Christmas songs with upbeat party tracks for later in the evening.

## Menu

1. **A traditional roast** is one of the mains.
2. **Drinks** include mulled wine and an alcohol-free mulled alternative.
3. **The almond game.** Dessert is rice pudding with one prize token hidden in it, and whoever finds it wins a prize. Traditionally the token is a whole almond. When any attending guest has a severe nut allergy, the allergy rules win: use a nut-free token (such as a whole cherry) and say so in the dessert's notes.
