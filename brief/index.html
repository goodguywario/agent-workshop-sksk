What is an agentic system?

Step through: you talk to the harness (opencode here; Claude Code and Codex are the same idea). The harness sends prompts to the LLM and gets replies back; the model does the thinking, the harness does the doing. The harness runs a primary agent, which delegates to sub-agents. Each sub-agent loads skills, its know-how, only when needed, and reaches the data through tools on the MCP server. The web app shows what's in the data. Last step: users don't have to use opencode at all. A button in the web app can start a containerized opencode session in an isolated sandbox (e.g. Sandcastle), which runs the same agents and skills against the same tools. Isolation is what makes this safe to offer to users.

Christmas Party Planner: How the app is built

npm run dev starts the frontend and its API. opencode starts the MCP server for the agents.

Top left: the user, who interacts with the frontend and drives opencode with /commands like /plan-party. Left to right: the web app users see, the SQLite database with the seeded event and guests (and the plan once it's made), and the MCP server, the only way the agents can touch the data. On the right: opencode runs the agents, and the agents load skills. Everything except agents and skills is the developers' work. Agents and skills are plain-language files, and that's where you come in today.
